# 脉钟签证（Pulse Clock Visa）

脉冲星计时小组的整周模糊假设分支工具。导入不同望次的脉冲到达时刻（TOA），
用频率、频率导数、色散量与仪器时钟事件解释残差；重点处理跨越多个自转
周期时的**整周模糊**——每个周数假设都是一个可保留、可对比、可重放的分支，
而不是只绘制一条拟合线。

## 运行

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm test -- --run          # 23 个自动化测试
corepack pnpm dev --host 127.0.0.1 --port 5505
# 打开 http://127.0.0.1:5505 ，应看到「脉钟签证」
```

技术栈：TypeScript + Node.js（内置 `node:http` / `node:sqlite`，零运行时依赖）
+ SQLite + Canvas（前端散点图）。测试用 Vitest。

## 数据口径

- **时刻**：以参考历元 T0 = MJD 59000.0 起的**整数微秒**（`tUs`）表示，
  SQLite 中以 TEXT 存储，读出即 BigInt。
- **频率 / 频率导数 / 色散量**：放大整数存储——
  `fNum = f[Hz]×1e12`，`dNum = fdot[Hz/s]×1e24`，`dmNum = DM[pc/cm³]×1e6`。
- **相位**：`φ = f·dt + ½·fdot·dt²`，以 `PHASE_DEN = 2e36` 为分母的
  有理数分子（BigInt）计算。
- **整周编号**：一律用 BigInt 向下取整除法（`floorDiv`）从相位分子得到，
  **绝不通过浮点取模推断大计数**（测试覆盖 ~1e12 周规模）。包裹相位仅
  在整数周确定后取余数转浮点用于展示。
- **时钟事件（共同事件）**：跳变量 = 记录时刻 − 真实时刻。在时刻边界上
  采用**右连续**语义：事件边界 `tEv` 对所有 `t >= tEv` 的到达时刻生效，
  恰落在观测时刻的跳变对该观测生效且仅生效一次。同一时刻的多个事件按
  **不可变事件序号 seq** 升序合成（折叠求和），与插入顺序无关。
- **色散改正**：`t_corr = t_obs − 时钟偏差 − K·DM/f²`，
  `K = 4.148808e9 µs·MHz²·(pc/cm³)⁻¹`，全部整数有理运算。
- **周数偏移（分支内）**：在空档边界 `B` 上施加 `delta` 周，对所有
  `t >= B` 的到达时刻生效（右连续），多个偏移按边界再按 id 合成。
- **残差**：`res = (φ(t_corr) − N) / f`，其中 `N = cycleBase + Σshift`
  为精确整数周；`cycleBase` 在导入时按参考参数四舍五入确定。
- **可识别性**：分支 RMS ≤ 25µs（噪声地板）视为「拟合可用」。若存在
  另一个周数方案（空档 ±1 周重拟合，或同版本上 shift 集合不同的兄弟
  分支）在全部共同观测点上与本分支不可区分，则两者都保留并标记
  **可识别性不足**；拟合不可用（RMS 过大）的方案标记为「被数据排除」。

## 固定 fixture

`fixtures/default.json`（由 `corepack pnpm gen-fixture` 确定性重新生成，
测试保证逐字节一致）：

- 10 Hz 脉冲星，fdot = −1e-15 Hz/s，DM = 30，三个频段（820/1400/2400 MHz）。
- 第 0..29 天每日一个 TOA → **200 天空档** → 第 230..234 天 5 个末端 TOA。
- 时钟事件：E1（+500µs）**恰好落在第 10 个 TOA 的记录时刻上**；
  E2/E3（+100/−30µs）位于同一时刻，验证按 seq 合成。
- 空档后 `+1 周` 与 `0 周` 两个方案在前半段等价，加入末端观测后才可区分。

## 操作页面

- 到达时刻表：MJD、观测频段、残差、包裹相位、整周编号、作用的时钟事件、
  排除候选勾选；空档位置以红线标出。
- 分支卡片：参数、残差摘要（RMS / max / 计数）、所依赖的输入版本、
  可识别性徽标；两个分支可**按观测点对比**（表格 + Canvas 双序列）。
- 操作：空档前后 ±1 周、添加共同时钟跳变、排除候选、回退末端数据
  （派生新输入版本）、新建/复制分支。

## 重放与复核

- **导出运行记录**：`GET /api/export` 或页面按钮，导出全部表
  （输入版本、TOA、时钟事件、分支、周数偏移、排除、运行日志）为 JSON。
- **清空重放**：页面「清空数据库」后用「重放导出包」导入
  （或 `POST /api/import-run`），所有分支摘要与导出前完全一致
  （`tests/api.test.ts` 自动验证该复核路径）。
- 数据库文件默认在 `data/pulse-clock-visa.sqlite`（可用 `PCV_DB` 覆盖）。

## 验收路径（已被自动化测试覆盖）

1. 导入完整 fixture，建分支 A（0 周）与 B（空档后 +1 周）：
   A 可识别（RMS ≈ 2.3µs），B 被数据排除（RMS ≈ 38ms）。
2. **回退末端数据**形成新输入版本，同样两个分支并列保留，
   均标记「可识别性不足」（残差完全一致）。
3. 时钟跳变恰落在观测时刻（第 10 个 TOA）时只应用一次：
   该点残差保持在噪声水平（若应用零次或两次将偏离 ±500µs）。
